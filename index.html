MealPrompt Studio · Un singur fișier. Fără instalare. Fără backend.
Ctrl / ⌘ + Enter generează

Un formular, apoi un copy.

1. Meniu: lipește planul actual sau importă un fișier text. Nu sunt acceptate PDF, imagini sau Word; copiază textul din ele.

2. Ținte: modifică kcal, proteinele, grăsimile și numărul de mese. Carbohidrații se pot calcula automat din energia rămasă. „Doar mesele incluse” nu este o dietă pentru întreaga zi.

3. Reguli și etichete: adaugă cerințe fixe, preferințe și valorile exacte ale produselor. Acestea înlocuiesc datele vechi pentru același ingredient.

4. Generează → Copiază: lipește rezultatul într-un chat nou. Aplicația nu trimite promptul, nu accesează contul tău și nu calculează meniul.

Offline: descarcă și deschide index.html în browser. Nu este nevoie de un server. Dacă browserul blochează copierea, butonul „Selectează tot” și Ctrl/⌘+C sunt alternative.

Salvare: draftul și profilurile sunt stocate local, necriptat. La deschiderea prin file://, persistența depinde de browser și de locația fișierului. Păstrează o copie JSON. Dezactivarea salvării elimină draftul, nu și profilurile salvate explicit.

Publicare: fișierul poate fi încărcat pe GitHub Pages. Pagina index.html din lista de fișiere GitHub afișează codul; aplicația se deschide local sau prin adresa GitHub Pages. Nu încărca exporturi personale în repository.

Configurații reutilizabile

Salvează câte un profil pentru fiecare meniu. Include textul meniului, țintele, regulile și etichetele; rămâne doar în acest browser.
